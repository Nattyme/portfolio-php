💻 **Developer Portfolio Website (PHP + Custom Admin Panel)**

Description:
This is an educational PHP project witth custom admin panel and structured MVC architecture.
The project includes sections such as Blog, Portfolio, Online Store, and Contacts, all managed dynamically from the admin area.

It was created to practice backend logic, database interactions, and content management using ReadBean ORM.

Main features:

- PHP templates and MVC architecture

- User authentication and profile editing

- Admin panel with content management for blog posts, portfolio projects, and shop items

- Contact form with message storage

- Integration with YooKassa for online payments

- Use of ReadBean ORM, CKEditor, and Composer

Tech stack:
PHP 8, MySQL, ReadBean ORM, HTML5, CSS3

Status:
Completed educational project

Demo: https://balashova-natalya.ru
